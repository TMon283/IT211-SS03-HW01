Câu 1:
Web Service là một hệ thống phần mềm cho phép các ứng dụng khác nhau
(có thể viết bằng ngôn ngữ lập trình khác nhau, chạy trên nền tảng khác nhau)
giao tiếp và trao đổi dữ liệu qua mạng, thường là Internet. Nó sử dụng các chuẩn mở
như HTTP, XML, JSON để đảm bảo tính tương thích.

Ví dụ thực tế: Dịch vụ thanh toán trực tuyến (PayPal, Momo, ZaloPay)
cung cấp Web Service để các website thương mại điện tử tích hợp chức năng thanh toán

Câu 2: Bảng so sánh SOAP và REST

| Tiêu chí               | SOAP                                                                 | REST                                           |
|------------------------|----------------------------------------------------------------------|------------------------------------------------|
| Giao thức truyền tải   | Chủ yếu dùng HTTP, nhưng cũng hỗ trợ SMTP, TCP                        | Chủ yếu dùng HTTP (GET, POST, PUT, DELETE)     |
| Định dạng dữ liệu chính| XML                                                                  | JSON (cũng có thể hỗ trợ XML, YAML, …)         |
| Trạng thái             | Có thể stateful hoặc stateless tùy thiết kế                          | Thường stateless (mỗi request độc lập, không lưu trạng thái phiên) |
| Tính dễ dàng triển khai| Phức tạp hơn, cần nhiều cấu hình, chuẩn nghiêm ngặt                   | Đơn giản, dễ triển khai, dễ tích hợp với ứng dụng web/mobile |

Câu 4: Ưu điểm của JSON so với XML trong việc truyền tải dữ liệu qua Web Service:
- Nhẹ và nhanh hơn: JSON có cú pháp ngắn gọn, ít ký tự thừa (không cần thẻ đóng/mở như XML),
  giúp giảm dung lượng truyền tải và tăng tốc độ xử lý
- Dễ đọc và dễ phân tích: JSON có cấu trúc gần giống với đối tượng trong các
  ngôn ngữ lập trình (JavaScript, Python…), nên dễ dàng parse và thao tác
- Tiêu tốn ít tài nguyên hơn: Do đơn giản và gọn nhẹ, JSON thường tiêu tốn ít CPU
  và bộ nhớ hơn khi xử lý so với XML
